# J2単体試験（#72）

11月14日に実機へ書き込んだ単発試験とJ2の指令幅をmainに移植した。配線を直した後の軸の回転は未確認。

## 既に試験版が入っている実機

1. 押し棒を外す。追加基板側の電源を抜き、XIAOのUSBだけをMacにつなぐ。115200 bpsのシリアルで `@j2-probe status` を送る。
2. `@j2-probe arm` を送り、`next_boot_armed=1` を確認する。予約は次の起動1回分。XIAOをMacから抜く。
3. J2の歯車が見える位置で追加基板側のUSBだけをつなぐ。起動5秒後に試験を要求し、保存済みの開始待ち時間を経て1回動く。ピンポンやスマホは不要。
4. 追加基板のUSBを抜いてからXIAOをMacに戻し、状態を読む。stageは0＝未予約、1＝予約、2＝消費、3＝要求、4＝ドライバ終了、5＝スキップ。軸の動きと戻りを目視で記録する。

## 新規チェックアウトからビルドする場合

下記のプロファイルはJ2を1500〜1700 µs、J3を1500〜1600 µsにする。実際の押し位置と戻り位置、保持時間、開始待ち時間には端末の保存済み校正値が優先される。試験時の設定は開始待ち500 ms、押し300 ms、戻り1000 ms。既にservo_config.hがある場合は、内容を比較してから試験用設定を適用する。

```sh
cd firmware/xiao
cp -n profiles/j2-probe/servo_config.example.h servo_config.h
bash run.sh test
bash run.sh build
```

現在の実機には個別の音声・通信設定もある。このブランチはJ2試験だけを移植したため、既に単体試験版が入っている端末では書き直さず上記のシリアル操作で再試験できる。
