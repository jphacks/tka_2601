VS-MGE20 / SG90 CAD・印刷データ一式

このセットはケース本体と操作機構の高速版です。Bambu Lab A1 mini、0.4 mmノズルで作成しています。

CAD: VS-MGE20_Case_SG90_square20.f3d
   Fusion 360の編集可能なアーカイブです。今回の手動ボタン用20 x 20 mm角穴を反映したモデルです。Fusion 360で開いて寸法や形状を編集できます。

1. Plate_02_main_PLA_square20_A1mini.gcode
   前面ガード（手動ボタン用の開口あり、再生キー位置は20 x 20 mm角穴）、ブリッジ、SG90固定部などの主要PLA部品。
   A1 mini用G-codeです。推定約2時間54分、PLA約47.7 g。サポートなし。
   同じプレートの編集用データはPlate_02_main_PLA_square20.3mfです。

2. Plate_03_small_PLA_parts.3mf / .stl
   SG90の押し子まわりの小型PLA部品。3MFをBambu Studioで開き、プリンターとフィラメントを確認してスライスしてください。

3. Plate_04_button_pads_TPU_reslice.3mf / .stl
   通話・終了ボタン用の柔らかいパッドです。TPUでの印刷を想定します。3MFは形状と配置の確認用で、印刷前にTPUプロファイルを選んで再スライスしてください。

注意:
- 前面ガードと機構を保持する充電台フレームは、この3時間以内を目指した高速版では省略しています。ブリッジの穴にバンドを通して固定します。
- Plate_02のスライサーは浮いた片持ち領域の警告を表示します。サポートなしの設定を使っています。印刷前に3MFを開いてプレビューを確認してください。
- 別機種のプリンターで印刷する場合、G-codeは使わず3MFを開いて、その機種向けに再スライスしてください。
