# PSoC Edge E84 AI Kit carrier notes

- Fusion design: `VS-MGE20_Case_SG90_v6_PSoC_Edge_E84_AI_M5StackBasic.f3d`
- Printed component: `Electronics_tray_PSoC_Edge_E84_AI_M5Stack_Basic.stl`
- Carrier plate: 174 x 72 x 2.8 mm; overall rail height 9.8 mm.
- The E84 board bay (98 x 56 mm) is a photo-scaled estimate, not a published board outline dimension. Check the actual KIT_PSE84_AI board and connector clearances before printing a final-fit part.
- M5Stack Basic retaining area is included on the same carrier.
- Slice profile: Bambu Lab A1 mini, 0.4 mm nozzle, Bambu PLA Basic, 0.12 mm High Quality, supports off.
- Bambu Studio estimated total: 1 h 34 min, 30.52 g.
